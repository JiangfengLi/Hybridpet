# 屠宰表现

当前入口仍为背包的屠宰拖放区，只接受背包中的生物，不消耗弹夹里的其他生物。

## 流程

1. `slayPal()` 从背包与活体列表移除选中的生物，关闭背包 UI，停止吸取及喷水。
2. `launchAnimal()` 同时服务普通投射与屠宰：向玩家正前方 6.4 米投射，时长 0.55 秒，沿现有抛物线旋转。
3. `updateSlaughter()` 使用 `updateAnimalTransition()` 推进投射；落地后膨胀 0.18 秒。
4. 爆炸时移除原生物模型，播放一次闷爆及黏稠水泡声，生成 32 个圆润红色液滴、10 个粉色气团和短暂闪光。
5. 留下 Q 版骨头遗体，交给刚体物理下落、碰撞和稳定。红色液滴落地摊开，整个临时特效在 4.6 秒后清理。

## 状态与资源

- `slaughterPhase`：`launch` → `anticipation` → `bones`。
- 生物一经确认屠宰，就退出活体 AI、吸取与库存；只有骨头阶段注册刚体，碰撞体随骨头尺寸缩放，不再沿用原生物体积。
- `corpses` 同时登记正在投射和已完成的屠宰对象，因此 UI 计数在接受操作时增加。
- 暂停、打开背包、播放结合演出或切到后台时，屠宰动画不推进。
- 未找到独立骨头模型文件，遗体使用项目已有的球体几何组合成圆润头骨和交叉骨头，不依赖外部下载。
- 原模型可能与其他生物共享资源，替换时不修改或释放其几何、材质、贴图。
- 临时爆炸最多同时保留 12 组，结束或淘汰时释放独占材质，共享几何不释放。

## 骨头刚体与堆叠

`bone-physics.mjs` 负责独立的遗骸物理世界，使用本地打包的 `vendor/cannon-es.mjs`，版本锁定为 0.20.0，许可证保存在 `vendor/cannon-es.LICENSE`。

- 每具遗骸是一个有质量的刚体，由底部交叉骨头、上部头骨两个简化盒体组成，不是逐三角形碰撞。
- 地面、场地边界和三座舱的边界为固定碰撞体；遗骸之间可互相碰撞、承托和堆叠。
- 向同一位置连续屠宰时，会根据现有堆叠高度调整落点，避免新骨头直接生成在旧骨头内部。
- 固定 60 Hz 物理步进，带摩擦、低弹性和休眠；不再用固定动画强制把骨头贴到地面。
- 玩家通过当前骨头包围体阻挡侧面穿行，并可从上方落在堆上。活体保留原平面绕行逻辑，但会检查高度，不会被头顶悬空的骨头挡住。
- 玩家与骨头使用简化包围体衔接，不是完整刚体角色控制器。没有新增抓取、搬运 UI。
- 暂停、背包、后台与全屏演出期间，物理不推进。

后续交互可使用模块的 `add()`、`remove()`、`teleport()`、`applyImpulse()`、`supportHeight()`。
运行时还提供以下接口，索引对应 `corpses`：

```js
boneRemains.getState(0); // mass, shapes, sleeping, bounds; null until bones exist
boneRemains.applyImpulse(0, {x: 1, y: 2, z: 0});
boneRemains.move(0, {x: 0, y: 3, z: 10}, 0); // position and yaw
```

## 音效

`playSlaughterPop()` 使用 Web Audio 程序生成短噪声、低频闷爆与下降音高的水泡，目标听感为鞭炮入水后的闷响和黏稠尾音。噪声缓冲只生成一次。

所有声部接入现有 `soundGain`，受主音量、音效音量、静音与暂停控制，不替换或重启背景音乐。投射激光声与落地爆炸声各触发一次。
