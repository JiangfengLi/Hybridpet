## 1. 目标与范围

以原 alien-walk 为运行主体，将调整建模风格后的太空舱结合系统接入原世界。
地图暂时只有一个太空舱；不用背包繁衍页和右键繁衍入口。
保留原游戏的后代遗传逻辑，重点是世界舱、结合动画与呈现效果。

代码接入不意味着完整动画已通过实机验收。当前不能标记集成完成。

## 2. 当前模块边界

```text
index.html
  原世界 / 玩家 / 库存 / breeding / 基因 / 真实实体
       |
       | host callbacks
       v
chamber-system.mjs
  一座舱的状态、亲代存取、任务、出生和领取调度
       |                         |
       v                         v
chamber-view.mjs          chamber-performance.mjs
  世界里的舱与轨迹          结合场景 / 演出输入 / 播放控制
                                 |
                       chamber-stage + fusion-v1
                         形变 / 接触 / 飞溅 / 声音 / DNA
                                 |
                       复用原游戏的 Renderer
```

`index.html` 仍是世界和真实实体的所有者，没有把原游戏换成独立太空舱演示页。
`chamber-system` 通过宿主函数调用原遗传和出生流程，不自行实现另一套遗传算法。
演出中的克隆网格不是库存或可捕获实体。

### 宿主适配契约

| 回调 | 当前职责 |
| --- | --- |
| `parents` / `job` / `remaining` | 读取唯一亲代对及孕育进度 |
| `deposit` | 从弹夹头部移入指定空槽 |
| `withdraw` | 将亲代移回弹夹，满时尝试背包 |
| `start` | 调用原 `startMate(0)`，确定本轮基因 |
| `preview` | 根据该基因创建演出预览模型 |
| `finish` | 调用 `birthOffspring(0, 'chamber')` 提交真实后代 |
| `receive` | 领取已有后代，弹夹优先、背包其次，拒绝重复收纳 |
| `setCinematic` | 切换演出状态，清除输入，处理指针锁与计时恢复 |
| `active` / `running` / `visible` | 分别约束交互、推进和近舱提示显示 |

`receive` 成功后，控制器才清空舱内后代；容量不足时不会主动删除该实体。
亲代存取在任务进行中被锁定。

## 3. 单舱状态与动画衔接

```text
loading --两只亲代 / startMate--> sealing
sealing --关门时间结束---------> generating 或 ready
generating --原孕育任务就绪----> ready
ready --E / 开始结合----------> playing
playing --返回---------------> ready
playing --演出完成且出生成功---> complete
complete --领取成功----------> loading
```

- 两槽填满后自动启动首次孕育；亲代保留时可通过交互再次启动。
- `task` 是控制器内的递增轮次，不是持久化或服务器任务 ID。
- 预览准备按轮次复用，返回和重播不调用 `startMate` 重新抽取。
- 重播重置动画会话；返回保留该轮任务并回到 `ready`。
- 演出内部按 10 次加速、4 轮强化、DNA 与出生展示推进。
- `performanceView.done` 后才请求宿主提交真实出生。
- 领取与出生分离；未领取成功时不启动下一轮。

近舱状态提示、投放/取回/交互按钮与演出控制仍保留。
移除的是旧背包繁衍页和右键入口，不是所有屏幕交互元素。

## 4. 分析快照之后的改动

### 观察窗与孕育期间的循环结合

后续请求将正面不透明舱门改为带边框的透明观察窗，不保留遮挡中心的实心面板和中缝。
窗片使用低透明度、不写深度、不投射阴影的材质，舱内增加局部照明。
此变更替代此前“不透明密封”的外观要求；关闭仍由门盖开度表达，而非不可见内部。

`chamber-view.mjs` 复用 `createGameActor`、`sampleCombination`、`waveSections`：

- 为每个亲代建立独立的形变展示副本，不改写原世界实体。
- 结合组固定朝向，统一缩放至 0.63，左右原点对齐原亲代槽。
- 舱门合拢、处于孕育阶段且剩余时间大于零时自动循环。
- 使用单独的 `incubationTime` 匀速推进，不调用 QTE、加速或强化会话。
- 通过 `combinationContacts` 的动作时间标记触发原结合碰撞音频。
- 倒计时完成时结束窗内循环；就绪、全屏演出、出生、领取仍沿用已有控制器流程。
- 开舱后隐藏形变副本，亲代恢复静止展示；下一轮从零开始。

`chamber-system.mjs` 管理窗内碰撞音频生命周期，开始任务时申请解锁，
在游戏暂停、页面隐藏、倒计时结束或玩家距离达到 18 米时停止。
音量随距离衰减，共用原静音状态。全屏演出声音仍由原演出模块管理。
`fusion-v1/combine-audio.js` 新增音量设置接口，原调用默认音量保持不变。

视图状态增加 `closed`、`observationWindow`、`incubating`、`incubationTime`；
旧 `opaque` 保留为 `false`，不再作为关门判据。
已更新旧不透明断言，并补充自动循环、暂停、不旋转、基因不变和开舱停止等断言。
这些断言尚未执行；观察窗的实际构图、碰撞声同步和性能尚未实机确认。
本次未重新打包发行版。

### 背景音乐与射击音效

按后续请求复制并接入 `assets/Audio_BackGround.mp3` 和 `assets/Audio_Laser.wav`。
`index.html` 的音频段负责循环背景音乐和有上限的 6 路射击音效播放，
原合成环境底音移除，其余程序化提示音保留。
`trySpit` 在确实发射后播放 Laser；舱的宿主 `sound('deposit')` 在成功投入后播放同一素材。
背景音乐初始音量为 32%，结合演出中降低为 14%，Laser 为 65%。

播放由开始游戏或后续用户手势触发；自动播放被拒绝后，不逐帧重试。
游戏暂停或页面隐藏时暂停背景音乐，恢复后续播。静音状态由原 `muted` 统一管理，

打包配置新增 `__background_audio` 和 `__laser_audio` 两个数据块；
`test/standalone.mjs` 补充两份素材的字节一致性断言，但未执行。

## 7. 后续重构的约束

- 保持原游戏世界和素材，不用独立演示场景替代原游戏。
- 始终只创建一个世界舱、两个亲代槽和一对原孕育任务。
- 真实基因、实体创建与库存归属仍由游戏宿主管理。
- 不因播放、退出、重播或重试抽取另一份后代基因。
- 先出生到舱，再领取入库存；容量不足不得丢失实体。
- 展示副本独立释放，不释放或改写真实亲代的几何和材质。
- 复用现有 Renderer，演出结束恢复世界渲染状态。
- 旧后端辅助函数和旧 CSS 的残留不代表仍有可达玩家入口。
- 保留完整动画范围，不以跳过强化、DNA 或出生动画换取更容易通过的流程。
