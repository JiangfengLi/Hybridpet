## 迁入功能

| 功能 | 迁移结果 |
| --- | --- |
| 背景 | 独立循环，诞生声音不覆盖音乐 |
| 射击 | 第二版 Laser，G 按下沿触发，忽略重复按键事件 |
| 行走与飞行 | 地面实际移动时循环 Grasswalk，飞行时循环 flight |
| 诞生 | 第二版“妈妈”单次播放，同时触发程序化烟花爆炸声音 |
| 结合碰撞 | 舱内和全屏演出均归类为音效 |
| 音量 | Esc 菜单包含主音量、背景、音效滑轨及静音，音量偏好本地保存 |
| 暂停 | 菜单暂停世界和音效，背景保留用于调节；页面隐藏时全部暂停 |
| 三座舱 | 01：(0,23)，02：(-18,23)，03：(18,23)，各自两亲代槽及后代领取状态 |
| 地图与环境 | 三个编号标记，三处碰撞与道具避让区域 |
| 玻璃 | 保留观察窗，合舱后匀速结合、无旋转，倒计时结束停止，开舱后不再结合 |

音量关系为“主音量 × 分类音量 × 单项基础音量”，舱内碰撞另乘距离衰减。
三座舱共用一个近舱面板及一个全屏演出播放器，避免重复绑定按钮和叠放全屏界面。
资源按“舱 ID + 本轮任务编号”区分，切舱后不会沿用其他舱的演出预览。

本次迁移以 A 的现有实现为准。A 本身未包含旧来源版本额外的 DNA 底部填色和
加量礼花，因此不额外引入这些差异；B 原有 DNA、礼花和后代朝向表现保留。

## 保留 B 的功能

- 36 位基因及 B 的模型描述、体型比例提示词。
- Tripo 服务端、运行时、Meshopt 解码、密钥配置、缓存和生成记录均保留。
- 各舱使用独立生成请求 ID；计时结束且本舱模型加载成功才能进入演出。
- 各舱独立显示进度、错误、继续查询和结束本轮孕育；重试沿用原请求和原基因。
- 放弃任务后的过期异步响应不能重新填回模型；不自动重提新付费任务。
- 模型来源、任务 ID、完整网格贴图、3000 三角面门槛、体型归一化和继代逻辑保留。
- B 在出生影片及开舱后让新生物面向玩家的逻辑保留；不影响亲代结合无旋转规则。
- `session.reset()` 重播修复保留。

`index.html` 的 `host(p)` 将存取、预览、重试、放弃、出生全部绑定至 `breeding.pairs[p]`。
`chamber-system.mjs` 每舱保留 `error` 阶段，并在当前面板读取该舱生成状态；
结束错误任务的面板按钮操作当前聚焦舱，不要求再次瞄准槽位。

`__chamberStatus(id)` 支持 ID 0–2，返回本舱状态及全部三舱的 `chambers` 数组。
