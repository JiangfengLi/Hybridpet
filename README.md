## 这是什么

一个浏览器端 3D 沙盒（Three.js，无框架）。保留原世界的走动、跳跃、飞行、
生物吸入和库存玩法。繁衍入口现为地图中的三座独立太空舱：
投入两个亲代 → 舱门关闭 → Tripo 生成并加载模型 → 结合演出 → 出生到舱 → 领取后代。
后代遗传继续使用原 alien-walk 逻辑。旧背包繁衍页与右键繁衍入口已移除。

### 方式二：双击 `start.bat`（跑真源码版）

`start.bat` 会在本机 **8766** 端口起一个本地游戏服务器（含 Tripo API 代理），然后自动打开浏览器。
需要机器上有 Python（脚本先找 `E:\anaconda\python.exe`，找不到就退回 PATH 里的 `python`）。

也可以手动起：

```
python serve.py 8799
# 然后打开 http://127.0.0.1:8799/
```

> ⚠️ **不要直接双击 `index.html`。** 它用 ESM 模块加载 `./vendor/` 与 `./models/`，
> `file://` 协议下会被浏览器的同源策略挡住。必须走本地 HTTP 服务器。
> 想双击就用上面的单文件版。

### 操作

| 键 | 作用 |
|---|---|
| WASD | 移动（飞行时是水平移动） |
| Shift | 冲刺（耗体力；飞行时是下降） |
| Space | 跳跃 · **快速连按两次**进入飞行 / 降落 |
| F | 原枪模式吸入生物；瞄准太空舱时优先取回亲代或领取后代 |
| G | 原枪模式发射弹夹首只；瞄准空亲代槽时优先投入 |
| E | 结合舱附近领取水枪，离开检测区后收起；其他阶段沿用舱体交互 |
| 左键 | 水枪模式下按住喷水、松开停止；原枪模式保留吸入 |
| B | 打开库存背包，不再包含繁衍页 |
| Alt | 显示鼠标，游戏继续运行；点击游戏画面恢复视角控制 |
| M | 切换背景音乐与游戏音效的静音状态；结合演出内使用声音按钮 |
| Esc | 打开/关闭暂停与音量菜单；演出中同样适用，退出演出用“返回”按钮 |

**繁衍**：01 舱位于 `x=0, z=23`，02 舱位于 `x=-18, z=23`，
03 舱位于 `x=18, z=23`，小地图显示各舱编号。每座独立存放亲代、
查询生成进度及领取后代；近舱面板优先选择瞄准舱，否则选择最近的舱。
用 G 向左右槽投入两只亲代，
填满后自动孕育。前后左右均有透明观察窗，舱门合拢后两只亲代在窗内匀速循环结合，
不旋转、不需要加速输入，并配有碰撞声和舱体晃动。
HTTP 模式显示本舱 API 返回的生成百分比，模型下载与解析成功后停止窗内循环，
就绪后按 E 或“开始结合”进入原有后续演出；若仍装备水枪，先按 E 收起。
离线模式明确显示“离线演示”百分比，默认用 15 秒演示占位模型流程，不调用 Tripo。
演出中按 Space 或“加速”完成 10 次输入，之后流程设计为自动进行 4 轮强化、DNA 和出生展示。
真实后代出生到舱内后再领取，优先进弹夹，其次进背包；两者都满则留在舱中。
亲代保留，可再次孕育。近舱提示与演出暂停、重播、返回、声音控制仍保留。
最后开舱时亲代恢复静止展示，不继续在舱内播放结合动作。

**水枪**：进入结合舱中心 10 米内可领取，喷射范围 12 米。前后左右命中都有效，
每座舱的数码 H2O 条独立累积，每秒增加 6 个百分点，最高 100%。
水枪仅在合舱结合期间增加状态值，不改变当前基因、API 生成速度或结果。
新一轮孕育及主动结束失败任务时清零，阈值回调支持后续扩展效果。

以上是源码流程，不是完整验收结论。暂停验证前，实机曾显示“强化结合 0 / 4”，
等待 DNA 阶段超时；原因未诊断，不能宣称全链路已经跑通。

### 修掉的两个缺陷

1. **`replay resets presses`（支线的真 bug）**：在 **QTE 阶段**点"重播"不会重置进度 ——
   因为 `createCombineSession().start()` 在 `state === 'running'` 时会早退，
   而重播是直接调 `start()` 的。在 surge / cinematic 阶段点则恰好能重置，
   所以这个 bug 只在**演出前半段**出现。修法：重播前先 `session.reset()`。
2. **`next generation reuses original inheritance`（融合引入的）**：该断言把基因长度写死成 `32`。
   改成跟 `GENE_COUNT` 走 —— 以后再加基因位不用回来改断言。

### 「卡在强化结合 0 / 4」的结论

支线文档里留着一个未诊问题：实机等待 DNA 阶段超时，界面停在"强化结合 0 / 4"。
**这次在真浏览器里复现不出来。** 新写的 `_probe_chamber.mjs` 把整场走了一遍：

```
密封(1.4 s) → 可以结合 → 按 E 进演出 → 扣 10 次空格(QTE)
→ 强化 0 → 1 → 2 → 3 → 4（**真的在推进，不是停在 0**）
→ cinematic: entry → drawing → weaving → coiling → sphere → separating → birth → result
→ 舱转入 complete（新生命诞生）→ 按 E 领取 → 回到等待亲代
```

从按完 QTE 到演出结束约 **16 秒**，全程 0 个控制台 error。
⇒ 那次卡住更可能是**环境性**的：演出推进挂在 `running && !paused && !document.hidden` 上
（`chamber-performance.mjs` 的 `update`），标签页失去可见性、被暂停、
开着背包面板、或用了 `&still=1` 都会让它停在原地。**不是强化算法坏了。**
